# ToyC 编译器实践报告

## 1. 项目概述

- 任务目标与语言范围
- 开发环境、C++20 与构建方式
- 小组成员及分工

## 2. 总体架构

编译流程：

```text
源码 -> Token -> AST -> 语义分析/常量求值 -> 三地址 IR -> RV32IM 汇编
```

说明各阶段输入、输出和模块边界。

## 3. 词法与语法分析

- Token 分类及注释处理
- 递归下降分析
- 运算符优先级和左结合性
- AST 节点设计

## 4. 语义分析

- 分层符号表与声明点可见性
- 全局、局部、形参和常量
- 函数签名与调用检查
- 常量表达式求值
- 循环上下文及返回值检查

## 5. 中间表示

- 虚拟寄存器
- 加载、存储、算术、调用、分支和返回指令
- `if`、`while`、`break`、`continue` 的控制流展开
- `&&` 与 `||` 的短路求值

## 6. RISC-V32 代码生成

- RV32IM 指令选择
- 栈帧布局
- 参数寄存器 `a0-a7` 与栈参数
- 返回地址、帧指针和递归调用
- 全局数据布局

## 7. 优化设计

- 已实现：命名常量传播、常量初始化求值、短路控制流
- 已实现：基本块内常量传播和常量折叠
- 已实现：热点局部变量寄存器化、活跃区间分析和线性扫描寄存器分配
- 已实现：短栈偏移指令选择，冲突虚拟寄存器自动溢出
- 已实现：死值/死存储删除、代数化简、只读全局传播和常量提升
- 已实现：尾递归消除、循环回边活跃区间修正和直接物理寄存器指令选择
- 已实现：带步骤预算和自动回退的 AST 全程序编译期求值
- 可扩展：公共子表达式消除和更精确的控制流图全局活跃性分析
