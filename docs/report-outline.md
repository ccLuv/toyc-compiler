# ToyC 编译器实现实验报告提纲

## 1. 项目概述

- 任务目标：实现 ToyC 到 RV32IM 汇编的编译器。
- 输入输出：从标准输入读取 ToyC 程序，向标准输出生成 GNU 汇编格式的 RISC-V32 汇编。
- 实现语言与环境：C++20，支持 Make/CMake 构建。
- 小组成员与分工：按最终报告填写。

## 2. 总体架构

编译流程：

```text
ToyC 源码 -> Token -> AST -> 语义分析 -> 三地址 IR -> IR 优化 -> RV32IM 汇编
```

各阶段均保留通用编译流程，不在编译阶段解释执行 `main`，也不把整个程序替换成预先算出的返回值。

## 3. 词法与语法分析

- 手写词法分析器，支持标识符、整数、关键字、运算符和注释。
- 递归下降语法分析器，处理声明、函数、语句和表达式。
- 按优先级解析一元、乘除模、加减、关系、相等、逻辑与、逻辑或表达式。
- 构建类型化 AST 作为后续语义分析和 IR 生成的输入。

## 4. 语义分析

- 分层符号表管理全局变量、局部变量、形参和常量。
- 检查重定义、未定义标识符、函数签名和调用参数数量。
- 对合法的常量表达式进行编译期求值，仅用于常量声明和初始化。
- 检查 `break`、`continue` 的循环上下文，以及 `return` 与函数返回类型的一致性。

## 5. 中间表示

- 使用三地址形式的虚拟寄存器 IR。
- IR 指令覆盖立即数、局部变量读写、全局变量读写、算术逻辑运算、标签、跳转、条件分支、函数调用和返回。
- `if`、`while`、`break`、`continue` 被展开为显式标签和跳转。
- `&&` 和 `||` 按短路语义生成控制流，保证副作用顺序正确。

## 6. RISC-V32 代码生成

- 生成 RV32IM 汇编，遵循整数调用约定。
- `a0-a7` 传递前 8 个参数，更多参数走栈。
- 维护栈帧、返回地址、保存寄存器和局部变量槽。
- 支持全局数据段、函数调用、递归调用和返回值传递。

## 7. 优化设计

- 常量传播、常量折叠和代数化简。
- 死值删除、死存储删除和结果依赖切片。
- 只读全局变量传播。
- 基本块内复制传播和公共子表达式消除。
- 尾递归消除，将特定尾调用转换为循环。
- while 循环旋转，减少热路径上的无条件跳转。
- 局部变量热度统计、线性扫描寄存器分配和溢出槽管理。
- 比较-分支融合、表达式结果直接写回等后端指令选择优化。

说明：优化阶段只对 IR 和汇编生成过程进行等价变换，不解释执行整个 ToyC 程序。

## 8. 测试

- 功能测试覆盖表达式、变量作用域、分支、循环、递归、多参数调用、全局变量、常量和短路表达式。
- 使用 RISC-V 工具链汇编链接，并通过 `qemu-riscv32` 运行验证退出码。
- 本地回归脚本：`bash tests/run_tests.sh`。

## 9. 问题与总结

- 当前实现侧重课程要求内的 ToyC 子集，没有实现完整 C 语言特性。
- 优化仍以局部优化和简单后端优化为主，缺少 SSA、全局值编号、循环不变量外提等更系统的优化框架。
- 合规版本不采用整程序求值来直接得到 `main` 返回结果，因此性能分可能低于此前激进版本，但更符合编译器任务要求。
